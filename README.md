# Aria: Your AI Companion

Build a modern, clean, and premium website for an AI called Aria.

About Aria:

•  Aria is an advanced AI assistant

•  Created by Kamran AKA Zaid Shaik

•  Intelligent, helpful, warm, and highly capable

•  Positioned as a personal/powerful AI companion

Website Goals: Create a beautiful landing page + full AI chat interface.

Pages & Features needed:

1.  Landing Page

	•  Hero section with big headline (something like “Meet Aria” or “Your Intelligent AI Companion”)

	•  Short description of Aria

	•  Clear “Chat with Aria” / “Try Aria” button

	•  Section about who built it (Kamran AKA Zaid Shaik)

	•  Clean modern design (dark mode preferred, elegant, minimal, high-end feel)

	•  Mobile responsive

2.  Chat Interface

	•  Full AI chat page (like ChatGPT style)

	•  Clean message bubbles

	•  User messages on the right, Aria on the left

	•  Input box at the bottom with send button

	•  Ability to start new chats

	•  Show Aria’s name and a nice avatar/logo

	•  Smooth animations

3.  About / Creator section

	•  Clearly mention: “Aria was created by Kamran AKA Zaid Shaik”

Design Style:

•  Modern, minimal, premium

•  Dark theme (deep black/dark gray + soft accent color like purple, blue, or cyan)

•  Beautiful typography

•  Smooth transitions and micro-interactions

•  Feels high-quality and trustworthy

Tech Preferences:

•  Use modern stack (Next.js + Tailwind preferred if possible)

•  Make it look production-ready

•  Fast and responsive

Extra:

•  Add a simple logo for Aria (just the letter “A” or a minimal brain/AI icon)

•  Make the overall vibe intelligent, calm, and futuristic

Start by creating the landing page + chat interface.
